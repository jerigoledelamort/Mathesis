## Формулировка

Для любого комплексного числа $z$ и любого натурального $n$ существует комплексное число $w$ такое, что $w^n = z$.

## Доказательство

Докажем индукцией по $n$.

**База: $n = 1$.** Корень первого порядка из $z$ — это само $z$. ✓

**База: $n = 2$.** По теореме [[T93. Существование квадратного корня из комплексного числа]], для любого $z \in \mathbb{C}$ существует $w$ такое, что $w^2 = z$. ✓

**Шаг: пусть утверждение верно для всех степеней, меньших $n$. Докажем для $n$.**

**Случай 1: $n$ чётное, $n = 2m$.** По индукционному предположению, существует $u \in \mathbb{C}$ такое, что $u^m = z$. По T93 существует $w$ такое, что $w^2 = u$. Тогда:

$$w^n = w^{2m} = (w^2)^m = u^m = z$$

**Случай 2: $n$ нечётное, $n \ge 3$.** Рассмотрим многочлен $p(w) = w^n - z$ с комплексными коэффициентами. По теореме [[T94. Основная теорема]], этот многочлен имеет хотя бы один корень $w_0 \in \mathbb{C}$, то есть $w_0^n = z$.

Таким образом, для любого $n$ корень существует. Теорема доказана.
