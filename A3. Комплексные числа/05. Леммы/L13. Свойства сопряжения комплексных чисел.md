## Формулировка

Для любых комплексных чисел $z, w \in \mathbb{C}$ выполняются следующие свойства:

1. $\overline{\overline{z}} = z$
2. $\overline{z + w} = \overline{z} + \overline{w}$
3. $\overline{z \cdot w} = \overline{z} \cdot \overline{w}$

## Доказательство

Пусть $z = (a, b)$, $w = (c, d)$.

1. **Инволютивность:** $\overline{z} = (a, -b)$. Тогда $\overline{\overline{z}} = (a, -(-b)) = (a, b) = z$.

2. **Сопряжение суммы:**  
   $z + w = (a + c, \ b + d)$.  
   $\overline{z + w} = (a + c, \ -(b + d)) = (a + c, \ -b - d)$.  
   С другой стороны, $\overline{z} + \overline{w} = (a, -b) + (c, -d) = (a + c, \ -b - d)$.  
   Следовательно, $\overline{z + w} = \overline{z} + \overline{w}$.

3. **Сопряжение произведения:**  
   $z \cdot w = (ac - bd, \ ad + bc)$.  
   $\overline{z \cdot w} = (ac - bd, \ -(ad + bc)) = (ac - bd, \ -ad - bc)$.  
   С другой стороны, $\overline{z} \cdot \overline{w} = (a, -b) \cdot (c, -d) = (a \cdot c - (-b)(-d), \ a(-d) + (-b)c) = (ac - bd, \ -ad - bc)$.  
   Следовательно, $\overline{z \cdot w} = \overline{z} \cdot \overline{w}$.

Лемма доказана.
