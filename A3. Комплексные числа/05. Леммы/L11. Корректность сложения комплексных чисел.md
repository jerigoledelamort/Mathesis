## Формулировка

Сложение комплексных чисел определено корректно: для любых комплексных чисел $z_1 = (a_1, b_1)$ и $z_2 = (a_2, b_2)$ их сумма $(a_1 + a_2, b_1 + b_2)$ является комплексным числом.

## Доказательство

По определению D29, $(a_1, b_1) + (a_2, b_2) = (a_1 + a_2, \ b_1 + b_2)$. Так как $a_1, a_2, b_1, b_2$ — вещественные числа, их суммы $a_1 + a_2$ и $b_1 + b_2$ также являются вещественными числами (поскольку $\mathbb{R}$ замкнуто относительно сложения, доказано в A2). Следовательно, результат является парой вещественных чисел, то есть комплексным числом по определению D27. Лемма доказана.
