## Определение

Сложение комплексных чисел выполняется по правилу:

Если $z_1 = (a, b)$ и $z_2 = (c, d)$ — комплексные числа, то их суммой называется комплексное число:

$$z_1 + z_2 = (a + c, \ b + d)$$

## Алгоритм

Чтобы сложить два комплексных числа:

1. Сложи их вещественные части: $a + c$.
2. Сложи их мнимые части: $b + d$.
3. Результат — пара $(a + c, \ b + d)$.

Пример: $(2, 3) + (4, 5) = (2+4, \ 3+5) = (6, 8)$.
