# Mathesis

### *Формальная система математики, построенная от аксиом до анализа*

---

## О проекте

**Mathesis** — это аксиоматическая база математического знания, в которой каждый результат выведен из предыдущих без пробелов и внешних ссылок. Проект построен по принципу слоистой архитектуры: каждая система надстраивается над предыдущей, расширяя множество объектов и доказывая новые свойства.

Здесь нет заимствованных определений. Нет «примем как очевидное». Всё начинается с двух базовых понятий — **ноль** и **следующий объект** — и из них, шаг за шагом, теорема за теоремой, вырастает вся математика: целые числа, рациональные, вещественные, комплексные, координатное пространство и функции.

> *Лучший способ понять математику — построить её заново.*

## Нумерация

Каждый объект имеет уникальный сквозной номер, по которому можно отследить цепочку рассуждений:

| Префикс | Тип | Диапазон |
|---------|-----|----------|
| **A** | Аксиомы | A1–A14 |
| **D** | Определения | D1–D142 |
| **O** | Операции | O1–O59 |
| **T** | Теоремы | T1–T262 |
| **L** | Леммы | L1–L28 |

Буквенные суффиксы (a, b) обозначают вспомогательные теоремы и леммы, являющиеся предпосылкой для основных: например, **L4** (знак нечётной степени) предшествует **L4a** (монотонность нечётной степени), а **T84a** (монотонность степени) предшествует **T85** (единственность корня).

## Философия

- **Минимум аксиом.** Тринадцать фундаментальных утверждений — и всё остальное выводится.
- **Сквозные доказательства.** Каждая теорема опирается только на предыдущие элементы системы. Никаких скачков, никаких внешних фактов.
- **Алгебраическая замкнутость без анализа.** Основная теорема алгебры (T94) доказана вторым методом Гаусса — чисто алгебраически, через индукцию по 2-адическому показателю степени, без обращения к теореме Лиувилля или комплексному анализу.
- **Мета-теоремы.** В систему включены доказательства непротиворечивости (T51) и инъективности операторов (T52).

## Ключевые достижения

### Арифметика (A0)
- Полная формализация целых чисел от шести аксиом
- Доказательство непротиворечивости через модель в целых числах (T51)
- Строгое доказательство $(-a)(-b) = ab$ индукцией (T37)
- Монотонность нечётной степени через лемму о знаке (L4 → L4a)

### Рациональные числа (A1)
- Построение поля $\mathbb{Q}$ как классов эквивалентности дробей
- Доказательство плотности рациональных чисел (T64)

### Вещественные числа (A2)
- Построение $\mathbb{R}$ через фундаментальные последовательности Коши
- Доказательство полноты по порядку — существование супремума (T82)
- Монотонность степени на $\mathbb{R}_{\ge 0}$ (T84a)
- Существование показательной функции и логарифма через фундаментальность рациональных степеней (T85a, T85b → T86, T87)
- Минимальность $\mathbb{R}$ как полного упорядоченного поля (T88)

### Комплексные числа (A3)
- Построение $\mathbb{C}$ как пар вещественных чисел
- Существование квадратного корня из любого комплексного числа (T93)
- **Основная теорема алгебры** — алгебраическое доказательство Гаусса (T94)
- Алгебраическая замкнутость $\mathbb{C}$ (T98)
- Минимальность $\mathbb{C}$ как алгебраически замкнутого расширения $\mathbb{R}$ (T99)

### Координатное пространство (A4)
- Точки, прямые, отрезки, лучи, углы
- Метрика $L_2$: $d(A,B) = \sqrt{\sum_{i=1}^{n}(a_i - b_i)^2}$
- Векторные операции над точками (D37a)
- Параллельность и перпендикулярность

### Функции (A5)
- Графики, область определения, область значений
- Предел функции в точке
- Непрерывность суммы, произведения, композиции
- Ассоциативность композиции

### Тригонометрия (A6)
- Определение sin/cos как координат на единичной окружности 
- Все табличные значения выведены из аксиом и алгебры 
- Комплексная экспонента $\exp(i	heta) := \cos	heta + i\sin	heta$ — как обозначение
- Формулы сложения выведены через метрику $L_2$ 
- Мультипликативность и степень $\exp$ доказаны через формулы сложения
- Корни $n$-й степени из комплексного числа (T134)
- $\pi$ введено как символ через аксиому; численное значение отложено

### Дифференциальное исчисление (A7)
- Арифметика пределов и теоремы о непрерывных функциях (IVT, максимум/минимум, равномерная непрерывность)
- Теория рядов: сходимость, признаки, степенные ряды
- Полный аппарат производных: правила дифференцирования, элементарные функции
- Основные теоремы: стационарная точка, нуль производной, среднее значение, правило раскрытия неопределённостей, теорема о разложении функции
- $\exp(x)$ определена через степенной ряд; $e := \exp(1)$
- Связь с A6: $\exp(i	heta) = \cos	heta + i\sin	heta$ доказана через ряды (T181)
- $e^x = \exp(x)$ обосновано (T179); $e = \lim(1+1/n)^n$ (T180)

### Интегральное исчисление (A8)
- Определённый интеграл через верхние и нижние суммы; критерий интегрируемости (T192)
- Непрерывные функции интегрируемы (T193)
- Основная теорема (FTC): интеграл с переменным пределом, формула вычисления через первообразную (T194–T196)
- Методы: замена переменной, по частям, дробно-рациональные (T197–T199)
- Применения: площадь, объём, длина дуги, поверхность вращения (T200–T203)
- Численное значение $\pi$ через длину окружности (T204) — замыкание A6
- $\ln(x) = \int_1^x \frac{dt}{t}$ (T205) — замыкание A7
- Табличные интегралы (T206–T218)

### Планиметрия (A9)
- Треугольники: сумма углов, признаки равенства (SAS, ASA, SSS), подобие
- Теорема о сторонах прямоугольного треугольника (T223) и обратная (T224)
- Четырёхугольники: свойства и признаки параллелограмма, прямоугольника, ромба, квадрата, трапеции
- Окружность: касательная, вписанный угол, хорды, вписанная и описанная окружности
- Площади: прямоугольник, параллелограмм, треугольник (через высоту и через стороны), трапеция, круг
- Параллельные прямые и пропорциональные отрезки

### Стереометрия (A10)
- Плоскость, параллельность и перпендикулярность прямых и плоскостей
- Признаки параллельности и перпендикулярности, теорема о трёх перпендикулярах
- Многогранники: призма, пирамида, теорема о вершинах, рёбрах и гранях
- Объёмы: призма, пирамида, цилиндр, конус, шар
- Площадь сферы: $S = 4\pi r^2$

## Как читать проект

Начните с файла **[00. Содержание](00.%20Содержание.md)** — он ссылается на содержания отдельных систем. Каждая система имеет собственный файл содержания (например, `A0. Содержание.md`) и введение (`00. Введение.md`).

Рекомендуемый способ чтения — через [Obsidian](https://obsidian.md/): все файлы связаны между собой через вики-ссылки `[[Название]]`, что позволяет свободно переходить от теоремы к её основам и обратно.

Файлы можно читать и в любом Markdown-редакторе — каждая ссылка соответствует имени файла.

### Рекомендуемый порядок

1. **[00. Содержание](00.%20Содержание.md)** — общая навигация
2. **[A0. Введение](A0.%20Основания/00.%20Введение.md)** — обзор целых чисел
3. **[A0. Содержание](A0.%20Основания/A0.%20Содержание.md)** — перечень объектов A0
4. Далее — по аналогии для каждой системы: введение → содержание → аксиомы → определения → операции → теоремы → леммы
