## Назначение

Имя файла должно однозначно определять тип математического объекта и его название.

---

## Формат

Каждый файл имеет следующий формат:

<Код>. <Название>

Примеры:

A1. Существование нуля

D4. Каноническая форма

O1. Сложение

T1. Единственность нормальной формы

---

## Коды

| Код | Значение    |
| --- | ----------- |
| A   | Аксиома     |
| D   | Определение |
| O   | Операция    |
| T   | Теорема     |
| L   | Лемма       |

---

## Нумерация

Нумерация ведётся отдельно внутри каждого типа.

Примеры:

A1
A2
A3

D1
D2
D3

O1
O2

T1
T2

---

## Правила

Каждый файл описывает только один объект.

Название должно быть кратким и однозначным.

После присвоения номер статьи не изменяется.
