## Формулировка

Всякая сходящаяся последовательность ограничена.

## Основано на

- [[D26. Сходимость последовательности вещественных чисел]]
- [[D25. Порядок вещественных чисел]]

## Доказательство

Пусть $x_n \to L$. По определению сходимости (D26), для $\varepsilon = 1$ существует $N$ такое, что для всех $n > N$: $|x_n - L| < 1$, то есть $|x_n| < |L| + 1$.

Для первых $N$ членов: $M_0 = \max\{|x_1|, \dots, |x_N|\}$.

Тогда для всех $n$: $|x_n| \le \max\{M_0, |L| + 1\}$. Последовательность ограничена.

Лемма доказана.
