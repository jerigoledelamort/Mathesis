## Формулировка

$$(\tan x)' = \frac{1}{\cos^2 x} = 1 + \tan^2 x$$

в точках, где $\cos x \neq 0$.

## Основано на

## Доказательство

По определению D61: $\tan x = \frac{\sin x}{\cos x}$. По правилу частного (T158):

$$(\tan x)' = \frac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x}$$

По T116: $\cos^2 x + \sin^2 x = 1$. Поэтому:

$$(\tan x)' = \frac{1}{\cos^2 x}$$

Альтернативная форма: $\frac{1}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = 1 + \tan^2 x$.

Теорема доказана.
