## Формулировка

$$(\sinh x)' = \cosh x, \qquad (\cosh x)' = \sinh x$$

$$(\tanh x)' = \frac{1}{\cosh^2 x}, \qquad (\coth x)' = -\frac{1}{\sinh^2 x}$$

## Доказательство

По определению D85: $\sinh x = \frac{\exp(x) - \exp(-x)}{2}$, $\cosh x = \frac{\exp(x) + \exp(-x)}{2}$.

Используя T163 ($\exp' = \exp$) и правило цепочки (T159) для $\exp(-x)$ (производная $= -\exp(-x)$):

$$(\sinh x)' = \frac{\exp(x) + \exp(-x)}{2} = \cosh x$$

$$(\cosh x)' = \frac{\exp(x) - \exp(-x)}{2} = \sinh x$$

Для $\tanh x = \frac{\sinh x}{\cosh x}$ по T158:

$$(\tanh x)' = \frac{\cosh^2 x - \sinh^2 x}{\cosh^2 x} = \frac{1}{\cosh^2 x}$$

(использовано тождество $\cosh^2 x - \sinh^2 x = 1$).

Теорема доказана.
