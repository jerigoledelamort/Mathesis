## Формулировка

Определение $\exp(i\theta) := \cos\theta + i\sin\theta$ из A6 (D64) согласовано с определением $\exp(x) = \sum_{n=0}^{\infty} \frac{x^n}{n!}$ из A7 (D82), а именно:

$$\exp(i\theta) = \sum_{n=0}^{\infty} \frac{(i\theta)^n}{n!} = \cos\theta + i\sin\theta$$

## Доказательство

Рассмотрим степенной ряд $\sum_{n=0}^{\infty} \frac{(i\theta)^n}{n!}$. Радиус сходимости $R = +\infty$ (T154), поэтому ряд сходится для всех $\theta \in \mathbb{R}$ (включая комплексные значения аргумента).

Разделим ряд на чётные и нечётные степени:

$$\sum_{n=0}^{\infty} \frac{(i\theta)^n}{n!} = \sum_{k=0}^{\infty} \frac{(i\theta)^{2k}}{(2k)!} + \sum_{k=0}^{\infty} \frac{(i\theta)^{2k+1}}{(2k+1)!}$$

Используя $i^{2k} = (-1)^k$ и $i^{2k+1} = (-1)^k \cdot i$:

$$= \sum_{k=0}^{\infty} \frac{(-1)^k \theta^{2k}}{(2k)!} + i \sum_{k=0}^{\infty} \frac{(-1)^k \theta^{2k+1}}{(2k+1)!}$$

Покажем, что первый ряд равен $\cos\theta$, а второй — $\sin\theta$.

**Ряд косинуса.** Рассмотрим $f(\theta) = \sum_{k=0}^{\infty} \frac{(-1)^k \theta^{2k}}{(2k)!}$. Этот ряд сходится абсолютно при всех $\theta$. Почленное дифференцирование даёт:

$$f'(\theta) = \sum_{k=1}^{\infty} \frac{(-1)^k \theta^{2k-1}}{(2k-1)!} = -\sum_{k=0}^{\infty} \frac{(-1)^k \theta^{2k+1}}{(2k+1)!} = -g(\theta)$$

где $g(\theta) = \sum_{k=0}^{\infty} \frac{(-1)^k \theta^{2k+1}}{(2k+1)!}$ — второй ряд.

Аналогично, $g'(\theta) = f(\theta)$.

Значит, $f'' = -f$ и $g'' = -g$, с начальными условиями $f(0) = 1$, $g(0) = 0$, $f'(0) = 0$, $g'(0) = 1$.

Функции $\cos\theta$ и $\sin\theta$ удовлетворяют тем же уравнениям и начальным условиям (по T162: $(\cos\theta)' = -\sin\theta$, $(\sin\theta)' = \cos\theta$, и L14: $\cos 0 = 1$, $\sin 0 = 0$). По единственности решения задачи Коши (аналог T178):

$$f(\theta) = \cos\theta, \qquad g(\theta) = \sin\theta$$

Следовательно:

$$\exp(i\theta) = \cos\theta + i\sin\theta$$

Это совпадает с определением D64 из A6. Таким образом, определение $\exp$ через степенной ряд (D82) и определение $\exp(i\theta) := \cos\theta + i\sin\theta$ (D64) согласованы.

Теорема доказана.

## Замечания

- Эта теорема замыкает круг: $\exp$ из A7 обобщает $\exp$ из A6 на все вещественные (и комплексные) аргументы.
- Из T177 следует $\exp(z_1 + z_2) = \exp(z_1)\exp(z_2)$ для комплексных $z_1, z_2$ (расширение T124 из A6).
- Теперь обозначение $e^{i\theta}$ для $\exp(i\theta)$ полностью обосновано: $e^z = \exp(z)$ для всех $z \in \mathbb{C}$ (T179).
