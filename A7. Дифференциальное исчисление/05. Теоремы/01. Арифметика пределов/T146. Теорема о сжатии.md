## Формулировка

Если $f(x) \le g(x) \le h(x)$ в окрестности точки $a$ и $\lim_{x \to a} f(x) = \lim_{x \to a} h(x) = L$, то:

$$\lim_{x \to a} g(x) = L$$

## Доказательство

Пусть $\varepsilon > 0$. По определению предела:

- Существует $\delta_1$ такое, что $|f(x) - L| < \varepsilon$ при $0 < |x-a| < \delta_1$, то есть $L - \varepsilon < f(x) < L + \varepsilon$.
- Существует $\delta_2$ такое, что $|h(x) - L| < \varepsilon$ при $0 < |x-a| < \delta_2$, то есть $L - \varepsilon < h(x) < L + \varepsilon$.

При $\delta = \min(\delta_1, \delta_2)$ и $0 < |x-a| < \delta$:

$$L - \varepsilon < f(x) \le g(x) \le h(x) < L + \varepsilon$$

Следовательно, $|g(x) - L| < \varepsilon$.

Теорема доказана.
