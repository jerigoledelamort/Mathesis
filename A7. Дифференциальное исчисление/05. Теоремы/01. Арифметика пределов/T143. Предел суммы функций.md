## Формулировка

Если $\lim_{x \to a} f(x) = L$ и $\lim_{x \to a} g(x) = M$, то:

$$\lim_{x \to a} [f(x) + g(x)] = L + M$$

---

- [[D52. Окрестность точки]]

## Доказательство

Пусть $\varepsilon > 0$. По определению предела (D53):

- Для $\frac{\varepsilon}{2}$ существует $\delta_1 > 0$ такое, что $0 < |x - a| < \delta_1 \implies |f(x) - L| < \frac{\varepsilon}{2}$.
- Для $\frac{\varepsilon}{2}$ существует $\delta_2 > 0$ такое, что $0 < |x - a| < \delta_2 \implies |g(x) - M| < \frac{\varepsilon}{2}$.

Положим $\delta = \min(\delta_1, \delta_2)$. Тогда при $0 < |x - a| < \delta$:

$$|f(x) + g(x) - (L + M)| \le |f(x) - L| + |g(x) - M| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$$

Теорема доказана.
