## Формулировка

Если для ряда $\sum a_n$ с положительными членами существует предел:

$$L = \lim_{n \to \infty} \frac{a_{n+1}}{a_n}$$

то:

- $L < 1$ — ряд сходится;
- $L > 1$ — ряд расходится;
- $L = 1$ — признак не даёт ответа.

## Доказательство

**$L < 1$.** Выберем $q$ с $L < q < 1$. При достаточно больших $n$: $\frac{a_{n+1}}{a_n} < q$, то есть $a_{n+1} < q \cdot a_n$. Тогда $a_{n+k} < q^k \cdot a_n$. Ряд сравнивается с геометрической прогрессией $\sum q^k$, которая сходится при $q < 1$. По T151, ряд сходится.

**$L > 1$.** При достаточно больших $n$: $a_{n+1} > a_n$, то есть члены не стремятся к нулю. По T150, ряд расходится.

Теорема доказана.
