## Формулировка

Для любых трёх точек $A, B, C$ расстояние удовлетворяет неравенству:

$$d(A, C) \le d(A, B) + d(B, C)$$

причём равенство достигается тогда и только тогда, когда точка $B$ лежит на отрезке $AC$.

## Доказательство

По аксиоме A9 (неравенство треугольника), входящей в аксиоматику метрики, для любых трёх точек выполняется:

$$d(A, C) \le d(A, B) + d(B, C)$$

Для метрики $L_2$ это неравенство выводится непосредственно. Пусть $u = A - B$, $v = B - C$ (векторные операции над точками, D37a). Тогда $A - C = u + v$ и:

$$d(A, C)^2 = \|u + v\|^2 = \sum_{i=1}^{n}(u_i + v_i)^2$$

По неравенству Коши–Буняковского (которое для сумм следует из T64a или непосредственно из $(u_i v_i)^2 \le u_i^2 v_i^2$):

$$\|u + v\| \le \|u\| + \|v\| = d(A, B) + d(B, C)$$

Равенство достигается когда $u$ и $v$ сонаправлены, то есть $B$ лежит на отрезке $AC$. Лемма доказана.
