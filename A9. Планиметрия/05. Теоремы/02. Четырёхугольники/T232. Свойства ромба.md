## Формулировка

В ромбе:

1. Все свойства параллелограмма.
2. Все стороны равны.
3. Диагонали перпендикулярны.
4. Диагонали делят углы ромба пополам.

## Доказательство

**1–2.** Ромб — частный случай параллелограмма, поэтому его свойства выполнены. Все стороны равны по определению.

**3.** Пусть $ABCD$ — ромб, диагонали пересекаются в $O$. По свойству параллелограмма $AO = OC$ и $BO = OD$. Треугольники $ABO$ и $CBO$ равны по SSS (T222): $AB = BC$, $AO = OC$, $BO$ общая. Значит $\angle AOB = \angle COB$. Эти углы смежные, значит каждый $90°$. Диагонали перпендикулярны.

**4.** Из равенства тех же треугольников: $\angle ABO = \angle CBO$, то есть диагональ $BD$ делит угол $B$ пополам. Аналогично для остальных углов.

Теорема доказана.
