## Формулировка

Сумма длин любых двух сторон треугольника больше длины третьей стороны:

$$a + b > c, \quad b + c > a, \quad a + c > b$$

---

## Основано на

- [[L28. Неравенство треугольника]]
- [[D98. Треугольник]]
- [[D37. Расстояние]]

---

## Доказательство

По лемме L28 (неравенство треугольника), для любых трёх точек $A, B, C$:

$$d(A, C) \le d(A, B) + d(B, C)$$

Если $A, B, C$ — вершины треугольника, то они не лежат на одной прямой, поэтому точка $B$ не лежит на отрезке $AC$. В этом случае неравенство строгое:

$$d(A, C) < d(A, B) + d(B, C)$$

то есть $b < a + c$. Аналогично для остальных пар. Теорема доказана.
