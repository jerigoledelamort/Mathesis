## Формулировка

Для любых рациональных чисел $q_1, q_2$:

$$q_1 + q_2 = q_2 + q_1$$

## Доказательство

Пусть $q_1 = \frac{a}{b}$, $q_2 = \frac{c}{d}$.

$$q_1 + q_2 = \frac{a d + b c}{b d} = \frac{c b + d a}{d b} = \frac{c}{d} + \frac{a}{b} = q_2 + q_1$$

Использовали коммутативность сложения и умножения целых чисел. Теорема доказана.
