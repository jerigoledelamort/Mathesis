## Формулировка

Для любых рациональных чисел $q_1, q_2, q_3$:

$$(q_1 + q_2) + q_3 = q_1 + (q_2 + q_3)$$

## Доказательство

Пусть $q_1 = \frac{a}{b}$, $q_2 = \frac{c}{d}$, $q_3 = \frac{e}{f}$.

Левая часть:

$$(q_1+q_2)+q_3 = \left(\frac{a}{b} + \frac{c}{d}\right) + \frac{e}{f} = \frac{a d + b c}{b d} + \frac{e}{f} = \frac{(a d + b c) f + (b d) e}{(b d) f}$$

Правая часть:

$$q_1+(q_2+q_3) = \frac{a}{b} + \left(\frac{c}{d} + \frac{e}{f}\right) = \frac{a}{b} + \frac{c f + d e}{d f} = \frac{a (d f) + b (c f + d e)}{b (d f)}$$

После раскрытия скобок и использования ассоциативности и коммутативности сложения и умножения целых чисел обе части равны:

$$\frac{a d f + b c f + b d e}{b d f}$$

Следовательно, по определению равенства дробей, они равны. Теорема доказана.
