## Формулировка

Для любых двух различных рациональных чисел $q_1 < q_2$ существует рациональное число $q_3$ такое, что $q_1 < q_3 < q_2$.

## Доказательство

Пусть $q_1 < q_2$. Рассмотрим $q_3 = \frac{q_1 + q_2}{2}$ (среднее арифметическое). Так как $q_1 < q_2$, то $q_1 + q_1 < q_1 + q_2 < q_2 + q_2$, откуда $2 q_1 < q_1 + q_2 < 2 q_2$. Деля на $2$ (положительное), получаем $q_1 < q_3 < q_2$. Теорема доказана.
