## Формулировка

Длина единичной окружности равна $2\pi$, откуда:

$$\pi = 2\int_{-1}^{1} \frac{dt}{\sqrt{1 - t^2}} = 2\int_0^1 \frac{dt}{\sqrt{1 - t^2}}$$

Это даёт численное значение $\pi \approx 3{,}14159\ldots$

## Доказательство

Единичная окружность (D58) задаётся параметризацией $\gamma(\theta) = (\cos\theta, \sin\theta)$ по A14. Верхняя полуокружность задаётся функцией $y = \sqrt{1 - x^2}$ при $x \in [-1, 1]$.

По T202, длина дуги:

$$L = \int_{-1}^{1} \sqrt{1 + y'(x)^2}\,dx$$

Вычислим $y' = \frac{-x}{\sqrt{1 - x^2}}$, тогда:

$$1 + y'^2 = 1 + \frac{x^2}{1 - x^2} = \frac{1}{1 - x^2}$$

Поэтому:

$$L = \int_{-1}^{1} \frac{dx}{\sqrt{1 - x^2}}$$

По A14, полная длина окружности равна $2\pi$ (параметр $\theta$ пробегает $[0, 2\pi]$). Верхняя полуокружность — половина длины, то есть $\pi$:

$$\pi = \int_{-1}^{1} \frac{dx}{\sqrt{1 - x^2}}$$

По симметрии (функция чётная):

$$\pi = 2\int_0^1 \frac{dx}{\sqrt{1 - x^2}}$$

Альтернативно, через замену $x = \sin t$ (T197):

$$\int_0^1 \frac{dx}{\sqrt{1 - x^2}} = \int_0^{\pi/2} \frac{\cos t\,dt}{\cos t} = \frac{\pi}{2}$$

что согласуется с результатом.

Теорема доказана.
