## Формулировка

Если $F$ — любая первообразная непрерывной функции $f$ на $[a, b]$, то:

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

---

## Основано на

- [[D92. Первообразная]]
- [[T195. Основная теорема (FTC, часть 1)]]
- [[T194. Интеграл с переменным верхним пределом]]
- [[T169. Теорема о среднем значении]]

---

## Доказательство

По T195, $G(x) = \int_a^x f(t)\,dt$ — первообразная $f$. Поскольку любые две первообразные отличаются на константу, $F(x) = G(x) + C$.

Вычислим $C$: $F(a) = G(a) + C = 0 + C = C$, поэтому $C = F(a)$.

Тогда:

$$\int_a^b f(x)\,dx = G(b) = F(b) - C = F(b) - F(a)$$

Теорема доказана.

---

## Замечания

- Это вторая часть основной теоремы (FTC), связывающая интеграл и производную.
- Обозначение: $F(b) - F(a) = \left[F(x)\right]_a^b$.
- Теорема выведена из T194–T195 без ссылок на внешние результаты.
