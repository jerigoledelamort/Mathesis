## Формулировка

Натуральный логарифм, определённый в A7 как обратная к $\exp$ (D83), выражается через интеграл:

$$\ln(x) = \int_1^x \frac{dt}{t}, \quad x > 0$$

## Доказательство

Определим $G(x) = \int_1^x \frac{dt}{t}$ для $x > 0$. По T195 (FTC, часть 1), $G$ дифференцируема и:

$$G'(x) = \frac{1}{x}$$

По T164, $\ln'(x) = \frac{1}{x}$ также. Значит, $G(x) = \ln(x) + C$ для некоторой константы $C$.

Вычислим $C$ при $x = 1$:

$$G(1) = \int_1^1 \frac{dt}{t} = 0, \qquad \ln(1) = 0$$

(так как $\exp(0) = 1$ по T177, значит $\ln(1) = 0$). Поэтому $C = 0$, и:

$$\ln(x) = \int_1^x \frac{dt}{t}$$

Теорема доказана.

---

## Замечания

- Эта теорема замыкает A7: $\ln$, определённый через обратную к $\exp$ (D83), получает интегральное представление.
- Теперь $\ln$ имеет три эквивалентных определения: обратная к $\exp$ (A7), интеграл от $1/t$ (T205), и первообразная $1/x$ (T164 + T195).
