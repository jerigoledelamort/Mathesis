## Формулировка

Для любого числа $a$ выполняются равенства:

$$a + 0 = a$$

$$0 + a = a$$

---

## Основано на

- [[D7. Число]]
- [[O1. Сложение]]
- [[D6. Равенство]]

---

## Доказательство

Пусть $a$ — произвольное число. По определению [[D7. Число]], $a$ является канонической формой некоторого выражения, то есть имеет вид $S^n(0)$ (при $n \ge 0$) или $P^n(0)$ (при $n \ge 0$), где при $n = 0$ это $0$. Следовательно, $a$ уже находится в нормальной форме и не требует нормализации: $NF(a) = a$.

Рассмотрим $a + 0$. По определению [[O1. Сложение]], сложение определяется как конкатенация последовательностей операторов с последующей нормализацией. Число $0$ представляется пустой последовательностью операторов (так как $0 = NF(0)$ и каноническая форма $0$ не содержит операторов). Поэтому запись $a + 0$ соответствует выражению, полученному применением к $0$ последовательности операторов, задающей $a$, а затем пустой последовательности. Иными словами, результирующее выражение есть в точности выражение, представляющее $a$. Поскольку $a$ уже является нормальной формой, его нормализация даёт само $a$:

$$NF(a + 0) = NF(a) = a$$

Аналогично для $0 + a$: пустая последовательность, за которой следует последовательность, представляющая $a$, даёт то же самое выражение, представляющее $a$:

$$NF(0 + a) = NF(a) = a$$

По определению [[D6. Равенство]], два выражения равны, если их нормальные формы совпадают. Следовательно:

$$a + 0 = a$$

$$0 + a = a$$

Теорема доказана.
