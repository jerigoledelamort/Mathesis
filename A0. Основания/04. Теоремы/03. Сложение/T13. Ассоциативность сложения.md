## Формулировка

Для любых чисел $a$, $b$, $c$ выполняется:

$$(a + b) + c = a + (b + c)$$

## Основано на

- [[D6. Равенство]]
- [[T2. Единственность нормальной формы]]
- [[L1. Коммутация нормализации с добавлением операторов]]

## Доказательство

Пусть $a$, $b$, $c$ — произвольные числа. Обозначим их последовательности операторов через $A$, $B$, $C$.

По определению [[O1. Сложение]]:

$$(a + b) + c = NF(NF(AB(0)) \cdot C(0))$$

Согласно [[L1. Коммутация нормализации с добавлением операторов]] (применённой последовательно к каждому оператору из $C$), нормализация внутри $AB(0)$ может быть выполнена до добавления $C$ без изменения результата. То есть:

$$NF(NF(AB(0)) \cdot C(0)) = NF(ABC(0))$$

Аналогично:

$$a + (b + c) = NF(A(0) \cdot NF(BC(0)))$$

Используя L1 для добавления $A$ к $BC$, получаем:

$$NF(A(0) \cdot NF(BC(0))) = NF(ABC(0))$$

Таким образом, оба выражения имеют одну и ту же нормальную форму:

$$NF((a + b) + c) = NF(ABC(0)) = NF(a + (b + c))$$

По определению [[D6. Равенство]]:

$$(a + b) + c = a + (b + c)$$

Теорема доказана.
