## Формулировка

Для любого числа $a$ существует число $-a$, называемое противоположным, такое что:

$$a + (-a) = 0$$

Число $-a$ определяется следующим образом:
- если $a = S^n(0)$, то $-a = P^n(0)$;
- если $a = P^n(0)$, то $-a = S^n(0)$;
- если $a = 0$, то $-a = 0$.

## Доказательство

Пусть $a$ — произвольное число. По определению [[D7. Число]], $a$ является канонической формой и имеет один из трёх видов: $0$, $S^n(0)$ с $n > 0$, или $P^n(0)$ с $n > 0$.

Рассмотрим каждый случай.

**Случай 1: $a = 0$.**  
Тогда $-a = 0$. Вычислим $a + (-a) = 0 + 0$. По определению [[O1. Сложение]], сложение есть конкатенация последовательностей операторов с последующей нормализацией. Пустая последовательность, объединённая с пустой, даёт пустую последовательность. Её нормализация даёт $0$. Следовательно:

$$a + (-a) = 0 + 0 = 0$$

**Случай 2: $a = S^n(0)$ с $n > 0$.**  
Тогда $-a = P^n(0)$. Рассмотрим выражение $a + (-a) = S^n(0) + P^n(0)$. По определению O1, это соответствует конкатенации последовательности из $n$ операторов $S$ и последовательности из $n$ операторов $P$:

$$S^n(0) + P^n(0) = NF(S^n P^n (0))$$

Выражение $S^n P^n (0)$ содержит $n$ пар $S P$, каждая из которых может быть сокращена по правилу $S(P(x)) \rightarrow x$ из [[D5. Нормализация]]. Последовательно применяя это правило $n$ раз, мы получим $0$. Согласно [[T2. Единственность нормальной формы]], результат нормализации не зависит от порядка сокращений, поэтому:

$$NF(S^n P^n (0)) = 0$$

Следовательно, по определению [[D6. Равенство]]:

$$a + (-a) = S^n(0) + P^n(0) = 0$$

**Случай 3: $a = P^n(0)$ с $n > 0$.**  
Тогда $-a = S^n(0)$. Рассуждение полностью симметрично случаю 2. Выражение $P^n(0) + S^n(0)$ соответствует $P^n S^n (0)$, содержащему $n$ пар $P S$, которые сокращаются по правилу $P(S(x)) \rightarrow x$. Нормализация даёт $0$:

$$NF(P^n S^n (0)) = 0$$

Следовательно:

$$a + (-a) = P^n(0) + S^n(0) = 0$$

Во всех случаях $a + (-a) = 0$. Теорема доказана.
