## Формулировка

Для любого числа $a$, если $b$ и $c$ такие числа, что $a + b = 0$ и $a + c = 0$, то $b = c$.

---

## Основано на

- [[T10. Нейтральный элемент]]
- [[T11. Противоположный элемент]]
- [[T12. Коммутативность сложения]]
- [[T13. Ассоциативность сложения]]
- [[L2. Совместимость сложения с равенством]]
- [[D6. Равенство]]
- [[T8E. Транзитивность равенства выражений]]

---

## Доказательство

Пусть $a$ — число, и пусть $b$, $c$ удовлетворяют:

$$a + b = 0 \tag{1}$$

$$a + c = 0 \tag{2}$$

Рассмотрим выражение $(a + b) + c$. По [[T13. Ассоциативность сложения]]:

$$(a + b) + c = a + (b + c) \tag{3}$$

С другой стороны, из (1) следует $a + b = 0$. Применим [[L2. Совместимость сложения с равенством]], добавляя $c$ к обеим частям равенства $a + b = 0$:

$$(a + b) + c = 0 + c$$

По [[T10. Нейтральный элемент]], $0 + c = c$. Следовательно:

$$(a + b) + c = c \tag{4}$$

Из (3) и (4) получаем:

$$a + (b + c) = c \tag{5}$$

Теперь рассмотрим $(a + c) + b$. Аналогично:

$$(a + c) + b = a + (c + b) \tag{6}$$

Из (2) следует $a + c = 0$. Применим L2, добавляя $b$:

$$(a + c) + b = 0 + b = b$$

По [[T12. Коммутативность сложения]], $c + b = b + c$, поэтому из (6):

$$a + (b + c) = b \tag{7}$$

Из (5) и (7) следует $b = c$ (по транзитивности, T8E).

Теорема доказана.
