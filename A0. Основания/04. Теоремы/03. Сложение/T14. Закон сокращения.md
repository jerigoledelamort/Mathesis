## Формулировка

Для любых чисел $a$, $b$, $c$, если $a + c = b + c$, то $a = b$.

---

## Основано на

- [[T10. Нейтральный элемент]]
- [[T11. Противоположный элемент]]
- [[T12. Коммутативность сложения]]
- [[T13. Ассоциативность сложения]]
- [[L2. Совместимость сложения с равенством]]
- [[D6. Равенство]]
- [[T8E. Транзитивность равенства выражений]]

---

## Доказательство

Пусть $a$, $b$, $c$ — числа, и пусть:

$$a + c = b + c \tag{1}$$

По [[T11. Противоположный элемент]], существует число $-c$ такое, что:

$$c + (-c) = 0$$

По [[T12. Коммутативность сложения]], $c + (-c) = (-c) + c$, следовательно:

$$(-c) + c = 0 \tag{2}$$

Применим [[L2. Совместимость сложения с равенством]] к равенству (1), добавляя $-c$ справа:

$$(a + c) + (-c) = (b + c) + (-c) \tag{3}$$

По [[T13. Ассоциативность сложения]] левая часть (3) преобразуется:

$$(a + c) + (-c) = a + (c + (-c))$$

По (2) и T10 (нейтральный элемент):

$$a + (c + (-c)) = a + 0 = a$$

Аналогично правая часть:

$$(b + c) + (-c) = b + (c + (-c)) = b + 0 = b$$

Из (3) следует $a = b$.

Теорема доказана.
