## Формулировка

Для любых чисел $a$ и $b$ выполняется:

$$a + b = b + a$$

---

## Основано на

- [[D7. Число]]
- [[O1. Сложение]]
- [[D6. Равенство]]
- [[T2. Единственность нормальной формы]]

---

## Доказательство

Пусть $a$ и $b$ — произвольные числа. По определению [[D7. Число]], каждое из них является канонической формой и представляется некоторой конечной последовательностью операторов. Обозначим эти последовательности через $A$ и $B$ соответственно. Тогда:

$$a = A(0)$$

$$b = B(0)$$

Рассмотрим выражение $a + b$. По определению [[O1. Сложение]], сложение есть конкатенация последовательностей операторов с последующей нормализацией:

$$a + b = NF(AB(0))$$

где $AB$ означает последовательность операторов $A$, за которой следуют операторы $B$.

Аналогично:

$$b + a = NF(BA(0))$$

Теперь рассмотрим инвариант $\Delta$, введённый при доказательстве [[T2. Единственность нормальной формы]]. Напомним, что для любого выражения $\Delta = \#S - \#P$, и этот инвариант не меняется при нормализации. Для выражения $AB(0)$ имеем:

$$\Delta(AB(0)) = \Delta(A(0)) + \Delta(B(0))$$

где $\Delta(A(0))$ и $\Delta(B(0))$ — это значения инварианта для чисел $a$ и $b$ соответственно. Аналогично для $BA(0)$:

$$\Delta(BA(0)) = \Delta(B(0)) + \Delta(A(0))$$

Сложение целых чисел (в смысле обычной арифметики) коммутативно, поэтому суммы равны:

$$\Delta(A(0)) + \Delta(B(0)) = \Delta(B(0)) + \Delta(A(0))$$

Следовательно:

$$\Delta(AB(0)) = \Delta(BA(0))$$

Из доказательства T2 мы знаем, что нормальная форма выражения полностью определяется значением $\Delta$. А именно:
- если $\Delta = 0$, нормальная форма равна $0$;
- если $\Delta = n > 0$, нормальная форма равна $S^n(0)$;
- если $\Delta = -n < 0$, нормальная форма равна $P^n(0)$.

Поскольку $\Delta(AB(0)) = \Delta(BA(0))$, их нормальные формы совпадают. Таким образом:

$$NF(AB(0)) = NF(BA(0))$$

По определению [[D6. Равенство]]:

$$a + b = b + a$$

Теорема доказана.
