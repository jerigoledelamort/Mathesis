## Формулировка

Для любых чисел $a$ и $b$ выполняется:

$$a - b = -(b - a)$$

---

## Основано на

- [[O2. Вычитание]]
- [[T10. Нейтральный элемент]]
- [[T11. Противоположный элемент]]
- [[T12. Коммутативность сложения]]
- [[T13. Ассоциативность сложения]]
- [[T15. Единственность противоположного элемента]]
- [[D6. Равенство]]
- [[T8E. Транзитивность равенства выражений]]

---

## Доказательство

Пусть $a$ и $b$ — произвольные числа. По определению [[O2. Вычитание]]:

$$a - b = a + (-b)$$

$$b - a = b + (-a)$$

Нам нужно доказать, что $a - b = -(b - a)$, то есть:

$$a + (-b) = -(b + (-a))$$

Достаточно показать, что $(a + (-b)) + (b + (-a)) = 0$, потому что тогда по определению противоположного элемента и [[T15. Единственность противоположного элемента]] число $a + (-b)$ будет противоположным к $b + (-a)$.

Рассмотрим сумму:

$$(a + (-b)) + (b + (-a))$$

По [[T13. Ассоциативность сложения]], перегруппируем слагаемые:

$$(a + (-b)) + (b + (-a)) = (a + (-a)) + (b + (-b))$$

По [[T12. Коммутативность сложения]], порядок не важен, поэтому группировка корректна.

По [[T11. Противоположный элемент]]:

$$a + (-a) = 0$$

$$b + (-b) = 0$$

Следовательно:

$$(a + (-a)) + (b + (-b)) = 0 + 0$$

По [[T10. Нейтральный элемент]], $0 + 0 = 0$. Таким образом:

$$(a + (-b)) + (b + (-a)) = 0$$

Это означает, что $a + (-b)$ является противоположным элементом к $b + (-a)$. По T15 (единственность противоположного элемента), противоположный элемент единственен, следовательно:

$$a + (-b) = -(b + (-a))$$

По определению O2, $a + (-b) = a - b$ и $b + (-a) = b - a$. Подставляя:

$$a - b = -(b - a)$$

Теорема доказана.
