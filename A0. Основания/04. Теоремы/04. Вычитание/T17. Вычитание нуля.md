## Формулировка

Для любого числа $a$ выполняется:

$$a - 0 = a$$

---

## Основано на

- [[O2. Вычитание]]
- [[T11. Противоположный элемент]]
- [[T10. Нейтральный элемент]]
- [[D6. Равенство]]

---

## Доказательство

Пусть $a$ — произвольное число. По определению [[O2. Вычитание]]:

$$a - 0 = a + (-0)$$

По определению противоположного элемента из [[T11. Противоположный элемент]], для числа $0$ противоположным является $0$ (так как $0 + 0 = 0$). Следовательно:

$$-0 = 0$$

Таким образом:

$$a - 0 = a + 0$$

По [[T10. Нейтральный элемент]], $a + 0 = a$. Следовательно:

$$a - 0 = a$$

Теорема доказана.
