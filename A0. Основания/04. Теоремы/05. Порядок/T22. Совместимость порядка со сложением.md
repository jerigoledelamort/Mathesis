## Формулировка

Для любых чисел $a$, $b$, $c$, если $a < b$, то $a + c < b + c$.

---

## Основано на

- [[D8. Отношение порядка]]
- [[O1. Сложение]]
- [[L2. Совместимость сложения с равенством]]
- [[T13. Ассоциативность сложения]]
- [[T12. Коммутативность сложения]]
- [[D6. Равенство]]

---

## Доказательство

Пусть $a$, $b$, $c$ — числа, и пусть $a < b$. По определению [[D8. Отношение порядка]]:

$$\exists k > 0 : a + S^k(0) = b \tag{1}$$

Прибавим $c$ к обеим частям равенства (1). По [[L2. Совместимость сложения с равенством]], из $x = y$ следует $x + c = y + c$. Поэтому:

$$(a + S^k(0)) + c = b + c \tag{2}$$

По [[T13. Ассоциативность сложения]], левая часть (2) преобразуется:

$$a + (S^k(0) + c) = b + c \tag{3}$$

По [[T12. Коммутативность сложения]], $S^k(0) + c = c + S^k(0)$. Подставляя в (3):

$$a + (c + S^k(0)) = b + c$$

Снова по ассоциативности T13:

$$(a + c) + S^k(0) = b + c \tag{4}$$

Из (4) следует, что существует положительное число $S^k(0)$ такое, что $(a + c) + S^k(0) = b + c$. По определению D8:

$$a + c < b + c$$

Теорема доказана.
