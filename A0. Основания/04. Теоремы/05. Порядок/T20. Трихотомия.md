## Формулировка

Для любых чисел $a$ и $b$ выполняется ровно одно из трёх утверждений:

$$a < b$$

$$a = b$$

$$a > b$$

## Доказательство

Пусть $a$ и $b$ — произвольные числа. Рассмотрим выражение $b - a$. По определению [[O2. Вычитание]]:

$$b - a = b + (-a)$$

По [[T11. Противоположный элемент]], для любого числа существует противоположное, поэтому $b - a$ является числом (канонической форму).

Согласно [[T4. Единственность канонической формы]], каждое число имеет единственную каноническую форму. Следовательно, $b - a$ имеет ровно один из трёх видов:

1. **$b - a = 0$**  
   Тогда по определению O2: $b + (-a) = 0$. Прибавим $a$ к обеим частям, используя [[L2. Совместимость сложения с равенством]]:  
   $(b + (-a)) + a = 0 + a$  
   По [[T13. Ассоциативность сложения]]: $b + ((-a) + a) = 0 + a$  
   По T11: $b + 0 = 0 + a$  
   По [[T10. Нейтральный элемент]]: $b = a$  
   То есть $a = b$.

2. **$b - a = S^k(0)$ с $k > 0$**  
   Тогда по определению [[D8. Отношение порядка]]: $a < b$.

3. **$b - a = P^k(0)$ с $k > 0$**  
   Тогда $b - a$ является отрицательным числом. Это означает, что $a - b = S^k(0)$ с $k > 0$ (поскольку $-(P^k(0)) = S^k(0)$ из определения противоположного элемента в T11). Следовательно, по определению D8: $b < a$, то есть $a > b$.

Поскольку $b - a$ имеет ровно одну каноническую форму (T4), случаи 1, 2, 3 взаимно исключают друг друга и покрывают все возможности.

Таким образом, для любых $a$ и $b$ выполняется ровно одно из трёх: $a < b$, $a = b$, $a > b$.

Теорема доказана.
