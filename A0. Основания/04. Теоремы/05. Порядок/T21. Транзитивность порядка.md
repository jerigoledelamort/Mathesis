## Формулировка

Для любых чисел $a$, $b$, $c$, если $a < b$ и $b < c$, то $a < c$.

---

## Основано на

- [[D8. Отношение порядка]]
- [[T13. Ассоциативность сложения]]
- [[O1. Сложение]]
- [[D6. Равенство]]

---

## Доказательство

Пусть $a$, $b$, $c$ — числа, и пусть $a < b$ и $b < c$. По определению [[D8. Отношение порядка]]:

$$a < b \Rightarrow \exists k > 0 : a + S^k(0) = b \tag{1}$$

$$b < c \Rightarrow \exists m > 0 : b + S^m(0) = c \tag{2}$$

Из (1) и (2) следует:

$$(a + S^k(0)) + S^m(0) = c$$

По [[T13. Ассоциативность сложения]]:

$$a + (S^k(0) + S^m(0)) = c \tag{3}$$

По определению сложения [[O1. Сложение]], $S^k(0) + S^m(0) = NF(S^k S^m (0)) = S^{k+m}(0)$. Поскольку $k > 0$ и $m > 0$, то $k + m > 0$. Таким образом, $S^{k+m}(0)$ — положительное число.

Из (3) следует, что существует положительное число $S^{k+m}(0)$ такое, что $a + S^{k+m}(0) = c$. Следовательно, по определению D8:

$$a < c$$

Теорема доказана.
