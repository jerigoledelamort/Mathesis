## Формулировка

Для любых выражений $E_1$ и $E_2$, если $E_1 = E_2$, то $S(E_1) = S(E_2)$ и $P(E_1) = P(E_2)$.

## Доказательство

Пусть $E_1$ и $E_2$ — произвольные выражения, и пусть $E_1 = E_2$. По определению [[D6. Равенство]], это означает, что:

$$NF(E_1) = NF(E_2)$$

Рассмотрим выражение $S(E_1)$. По [[L1. Коммутация нормализации с добавлением операторов]]:

$$NF(S(E_1)) = NF(S(NF(E_1)))$$

Аналогично для $S(E_2)$:

$$NF(S(E_2)) = NF(S(NF(E_2)))$$

Так как $NF(E_1) = NF(E_2)$ (по условию), то выражения $S(NF(E_1))$ и $S(NF(E_2))$ совпадают (добавление $S$ к одинаковым объектам даёт одинаковые выражения). Следовательно, их нормальные формы также совпадают:

$$NF(S(NF(E_1))) = NF(S(NF(E_2)))$$

Отсюда:

$$NF(S(E_1)) = NF(S(E_2))$$

По определению D6 это означает $S(E_1) = S(E_2)$.

Доказательство для $P$ полностью аналогично с использованием L1 для оператора $P$:

$$NF(P(E_1)) = NF(P(NF(E_1))) = NF(P(NF(E_2))) = NF(P(E_2))$$

Следовательно, $P(E_1) = P(E_2)$.

Таким образом, операторы $S$ и $P$ совместимы с равенством выражений. Теорема доказана.
