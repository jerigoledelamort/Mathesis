## Формулировка

Для любых чисел $a$, $b$, $c$:

$$d(a, c) \le d(a, b) + d(b, c)$$

---

## Основано на

- [[D10. Расстояние]]
- [[D9. Абсолютная величина]]
- [[D8. Отношение порядка]]
- [[T22. Совместимость порядка со сложением]]
- [[T13. Ассоциативность сложения]]
- [[T12. Коммутативность сложения]]
- [[D6. Равенство]]

---

## Доказательство

Пусть $a$, $b$, $c$ — произвольные числа. По определению [[D10. Расстояние]]:

$$d(a, c) = |a - c|$$

$$d(a, b) = |a - b|$$

$$d(b, c) = |b - c|$$

Заметим, что $a - c = (a - b) + (b - c)$ (это следует из определения вычитания и свойств сложения; формально: $(a - b) + (b - c) = a + (-b) + b + (-c) = a + 0 + (-c) = a - c$).

Таким образом, достаточно доказать, что для любых чисел $x$ и $y$:

$$|x + y| \le |x| + |y|$$

Это неравенство называется неравенством треугольника для модуля. Докажем его.

По определению [[D9. Абсолютная величина]], для любого числа $t$ справедливо $t \le |t|$ и $-t \le |t|$ (это следует из разбора случаев: если $t \ge 0$, то $t = |t|$; если $t < 0$, то $t < |t|$ и $-t = |t|$). Следовательно:

$$x \le |x|, \quad y \le |y|$$

По [[T22. Совместимость порядка со сложением]], складывая эти неравенства, получаем:

$$x + y \le |x| + |y|$$

Аналогично, $-x \le |x|$ и $-y \le |y|$, следовательно:

$$-(x + y) = (-x) + (-y) \le |x| + |y|$$

Таким образом, $x + y \le |x| + |y|$ и $-(x + y) \le |x| + |y|$. Это означает, что $|x + y| \le |x| + |y|$ (по определению модуля: если $x+y \ge 0$, то $|x+y| = x+y$; если $x+y < 0$, то $|x+y| = -(x+y)$; в обоих случаях значение не превосходит $|x|+|y|$).

Теперь подставим $x = a - b$ и $y = b - c$:

$$|(a - b) + (b - c)| \le |a - b| + |b - c|$$

$$|a - c| \le |a - b| + |b - c|$$

По определению D10, это в точности:

$$d(a, c) \le d(a, b) + d(b, c)$$

Теорема доказана.
