## Формулировка

Для любых чисел $a$ и $b$:

$$d(a, b) = 0 \iff a = b$$

---

## Основано на

- [[D10. Расстояние]]
- [[T26. Модуль нуля]]
- [[O2. Вычитание]]
- [[T11. Противоположный элемент]]
- [[T10. Нейтральный элемент]]
- [[T13. Ассоциативность сложения]]
- [[L2. Совместимость сложения с равенством]]
- [[D6. Равенство]]

---

## Доказательство

Пусть $a$ и $b$ — произвольные числа. По определению [[D10. Расстояние]]:

$$d(a, b) = |a - b|$$

**($\Rightarrow$)** Предположим, $d(a, b) = 0$. Тогда $|a - b| = 0$. По [[T26. Модуль нуля]], $|a - b| = 0 \iff a - b = 0$. По определению [[O2. Вычитание]], $a - b = a + (-b)$. Итак, $a + (-b) = 0$. Прибавим $b$ к обеим частям, используя [[L2. Совместимость сложения с равенством]]:

$$(a + (-b)) + b = 0 + b$$

По [[T13. Ассоциативность сложения]]: $a + ((-b) + b) = 0 + b$.

По [[T11. Противоположный элемент]], $(-b) + b = 0$, значит $a + 0 = 0 + b$.

По [[T10. Нейтральный элемент]], $a = b$. Следовательно, $a = b$.

**($\Leftarrow$)** Если $a = b$, то $a - b = 0$. Тогда $|a - b| = |0| = 0$ (по T26). Следовательно, $d(a, b) = 0$.

Таким образом, $d(a, b) = 0 \iff a = b$. Теорема доказана.
