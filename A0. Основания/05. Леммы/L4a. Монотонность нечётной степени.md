## Формулировка

Для любого нечётного $n = 2k+1$ и любых чисел $a, b$, если $a < b$, то $a^n < b^n$.

## Доказательство

Докажем индукцией по $k$ (где $n = 2k+1$).

**База: $k = 0$ (n = 1).**  
Если $a < b$, то по определению $a^1 = a$ и $b^1 = b$, значит $a^1 < b^1$. Утверждение верно.

**Шаг: пусть утверждение верно для $2k+1$. Докажем для $2(k+1)+1 = 2k+3$.**

Пусть $a < b$. Рассмотрим разность:

$$b^{2k+3} - a^{2k+3} = (b - a) \cdot S,$$

где $S = b^{2k+2} + b^{2k+1}a + b^{2k}a^2 + \dots + a^{2k+2}$ (всего $2k+3$ слагаемых).

Так как $b - a > 0$, достаточно показать, что $S > 0$.

Разобьём доказательство на случаи.

**Случай 1: $a \ge 0$.**  
Тогда все степени неотрицательны, и все слагаемые в $S$ неотрицательны. При этом первое слагаемое $b^{2k+2} > 0$ (так как $b > a \ge 0$, значит $b > 0$). Следовательно, $S > 0$.

**Случай 2: $a < 0$.**  
Пусть $a = -c$ с $c > 0$. Тогда $b > -c$. Рассмотрим два подслучая.

**Подслучай 2.1: $b \ge 0$.**  
По [[L4. Знак нечётной степени]], $a^n < 0$ (так как $a < 0$ и $n$ нечётно). С другой стороны, $b \ge 0$, значит $b^n \ge 0$ (все слагаемые в произведении неотрицательны). Следовательно, $a^n < 0 \le b^n$, то есть $a^n < b^n$.

**Подслучай 2.2: $b < 0$.**  
Тогда оба числа отрицательны. Пусть $b = -d$ с $d > 0$. Тогда $a = -c$ и $b = -d$, причём $-d > -c$, значит $d < c$. Тогда $a^n = (-c)^n = -c^n$ (так как $n$ нечётное), $b^n = (-d)^n = -d^n$. Так как $d < c$, то $d^n < c^n$, следовательно $-c^n < -d^n$, то есть $a^n < b^n$. Это доказывает утверждение в этом подслучае напрямую, без разности.

Таким образом, во всех случаях $a^n < b^n$. Индукция завершена. Лемма доказана.
