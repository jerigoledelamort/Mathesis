## Формулировка

Для любого числа $a < 0$ и любого нечётного $n = 2k+1$ (где $k \ge 0$) выполняется:

$$a^n < 0$$

## Доказательство

Пусть $a < 0$. Представим $a = (-1) \cdot c$, где $c = -a > 0$ (по T11, $-a$ существует и положителен).

По теореме [[T48. Степень произведения]]:

$$a^n = ((-1) \cdot c)^n = (-1)^n \cdot c^n$$

**Шаг 1: $(-1)^n = -1$ для нечётного $n$.**

Докажем индукцией по $k$ (где $n = 2k+1$).

- **База: $k = 0$ ($n = 1$).** $(-1)^1 = -1$ по определению степени (O5). ✓

- **Шаг: пусть $(-1)^{2k+1} = -1$. Докажем $(-1)^{2k+3} = -1$.**

  $$(-1)^{2k+3} = (-1)^{2k+1} \cdot (-1)^2$$

  по [[T46. Сложение показателей]]. По индукционному предположению $(-1)^{2k+1} = -1$. Далее, $(-1)^2 = (-1) \cdot (-1) = 1$ по [[T37. Произведение двух отрицательных]]. Следовательно:

  $$(-1)^{2k+3} = (-1) \cdot 1 = -1$$

  по [[T32. Умножение на единицу]]. ✓

**Шаг 2: $c^n > 0$ для $c > 0$.**

Так как $c > 0$, по [[L3. Положительность произведения]] $c \cdot c > 0$. Индукцией по $n$: $c^1 = c > 0$; если $c^n > 0$, то $c^{n+1} = c^n \cdot c > 0$ по L3. Следовательно, $c^n > 0$ для всех $n \ge 1$.

**Шаг 3: $a^n = (-1)^n \cdot c^n = (-1) \cdot c^n = -(c^n) < 0$.**

Последнее равенство следует из [[T36. Умножение на отрицательное]]: $(-1) \cdot c^n = -(1 \cdot c^n) = -(c^n)$. Так как $c^n > 0$, то $-(c^n) < 0$.

Лемма доказана.
