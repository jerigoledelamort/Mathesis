## Формулировка

Для любого выражения $E$ и любого оператора $O \in \{S, P\}$ выполняется:

$$NF(O(E)) = NF(O(NF(E)))$$

---

## Основано на

- [[D2. Выражение]]
- [[D5. Нормализация]]
- [[T1. Конечность нормализации]]
- [[T2. Единственность нормальной формы]]

---

## Доказательство

Введём обозначение: $E \rightarrow E'$ означает, что выражение $E'$ получено из $E$ применением ровно одного правила сокращения из [[D5. Нормализация]] (то есть заменой подслова $S P$ или $P S$ на пустую строку).

Докажем следующую лемму: если $E \rightarrow E'$, то для любого оператора $O \in \{S, P\}$ выполняется $O(E) \rightarrow O(E')$ (то есть сокращение внутри $E$ сохраняется при добавлении внешнего оператора).

Это утверждение очевидно, поскольку сокращение происходит внутри выражения $E$ и не затрагивает внешний оператор $O$. Добавление $O$ в начало не мешает применению того же правила сокращения внутри $E$. Таким образом, если в $E$ есть подслово $S P$ или $P S$, то в $O(E)$ оно также присутствует, и его можно сократить.

Теперь докажем основное утверждение индукцией по числу шагов нормализации $E$, обозначим его через $k(E)$. Согласно [[T1. Конечность нормализации]], $k(E)$ конечно для любого выражения $E$.

**База индукции:** $k(E) = 0$, то есть $E$ уже является нормальной формой. Тогда $NF(E) = E$, и утверждение $NF(O(E)) = NF(O(NF(E)))$ тривиально.

**Шаг индукции:** Пусть $k(E) = n > 0$. Тогда существует выражение $E'$ такое, что $E \rightarrow E'$ и $k(E') = n - 1$. По доказанной выше лемме, $O(E) \rightarrow O(E')$.

Поскольку $O(E) \rightarrow O(E')$, их нормальные формы совпадают согласно [[T2. Единственность нормальной формы]] (применение одного сокращения не меняет конечный результат нормализации). Следовательно:

$$NF(O(E)) = NF(O(E'))$$

По индукционному предположению для $E'$ (так как $k(E') < k(E)$) имеем:

$$NF(O(E')) = NF(O(NF(E')))$$

Также из $E \rightarrow E'$ следует, что $NF(E) = NF(E')$ по T2 (единственность нормальной формы для одного и того же выражения). Поэтому:

$$NF(O(NF(E'))) = NF(O(NF(E)))$$

Собирая цепочку равенств:

$$NF(O(E)) = NF(O(E')) = NF(O(NF(E'))) = NF(O(NF(E)))$$

Таким образом, $NF(O(E)) = NF(O(NF(E)))$.

Лемма доказана.
