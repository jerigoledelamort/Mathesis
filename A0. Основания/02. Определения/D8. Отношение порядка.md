## Определение

Для любых чисел $a$ и $b$:

$$a < b \iff \exists k > 0 : a + S^k(0) = b$$

Другими словами, $a < b$ тогда и только тогда, когда разность $b - a$ является положительным числом (имеет вид $S^k(0)$ с $k > 0$).

Аналогично:

$$a > b \iff b < a$$

$$a \le b \iff (a < b \text{ или } a = b)$$

$$a \ge b \iff (a > b \text{ или } a = b)$$
