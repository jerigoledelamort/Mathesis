## Определение

Сложение вещественных чисел выполняется по правилу:

Если $x = [(\alpha_n)]$ и $y = [(\beta_n)]$ — вещественные числа (классы эквивалентности фундаментальных последовательностей), то их суммой называется класс эквивалентности последовательности $(\alpha_n + \beta_n)$:

$$x + y = [(\alpha_n + \beta_n)]$$

## Алгоритм

Чтобы сложить два вещественных числа:

1. Выбери любые две фундаментальные последовательности рациональных чисел, представляющие эти числа: $(\alpha_n)$ для $x$ и $(\beta_n)$ для $y$.
2. Построй новую последовательность $(\gamma_n)$, где $\gamma_n = \alpha_n + \beta_n$ для каждого $n$.
3. Результатом сложения будет класс эквивалентности последовательности $(\gamma_n)$.

Пример: пусть $x = [(\frac{1}{n})]$ и $y = [(\frac{2}{n})]$. Тогда $x+y = [(\frac{1}{n} + \frac{2}{n})] = [(\frac{3}{n})]$.
