## Формулировка

Существует вещественное число $0_{\mathbb{R}} = [(0, 0, 0, \dots)]$ такое, что для любого вещественного $x$:

$$x + 0_{\mathbb{R}} = x$$

---

## Основано на

- [[O11. Сложение вещественных чисел]]
- [[T56. Существование нейтрального элемента по сложению]]
- [[D6. Равенство]]

---

## Доказательство

Пусть

$$x=[(\alpha_n)]$$

и пусть

$$0_{\mathbb{R}}=[(0,0,0,\dots)].$$

По определению сложения вещественных чисел:

$$
x+0_{\mathbb{R}} = [(\alpha_n+0)].
$$

Для каждого $n$ выполняется

$$
\alpha_n+0=\alpha_n
$$

по свойству нейтрального элемента для рациональных чисел (теорема [[T56. Существование нейтрального элемента по сложению]]).

Значит, последовательность $(\alpha_n+0)$ совпадает с $(\alpha_n)$ покоординатно, а потому определяет тот же класс эквивалентности. Следовательно,

$$x+0_{\mathbb{R}}=x.$$

Теорема доказана.
