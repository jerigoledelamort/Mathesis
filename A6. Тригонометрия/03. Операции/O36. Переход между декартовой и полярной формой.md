## Определение

Операция перехода между декартовой и полярной формой комплексного числа.

**Декартова → полярная:** для $z = a + bi \neq 0$:

$$r = \sqrt{a^2 + b^2}, \qquad \theta = \arctan\frac{b}{a} \text{ (с учётом знаков } a, b\text{)}$$

**Полярная → декартова:**

$$a = r\cos\theta, \qquad b = r\sin\theta$$

## Алгоритм

**Декартова → полярная:**
1. Вход: $z = a + bi$.
2. Вычислить $r = \sqrt{a^2 + b^2}$.
3. Определить $\theta$ по знакам $a$ и $b$: если $a > 0$, то $\theta = \arctan(b/a)$; если $a < 0$, то $\theta = \arctan(b/a) + \pi$; если $a = 0$, то $\theta = \pi/2$ при $b > 0$ или $\theta = -\pi/2$ при $b < 0$.
4. Выдать $(r, \theta)$.

**Полярная → декартова:**
1. Вход: $(r, \theta)$.
2. Вычислить $a = r\cos\theta$, $b = r\sin\theta$.
3. Выдать $z = a + bi$.
