## Формулировка

Единичная окружность в $\mathbb{R}^2$ допускает непрерывную биекцию $\gamma: [0, 2\pi) \to S^1$, где $S^1$ — единичная окружность, а $\pi$ — некоторое положительное вещественное число, такую что:

1. $\gamma(0) = (1, 0)$.
2. Для любых $\alpha, \beta \in [0, 2\pi)$ равным длинам дуг соответствуют равные хорды: если $|\alpha - \beta| = |\alpha' - \beta'|$, то $|\gamma(\alpha) - \gamma(\beta)| = |\gamma(\alpha') - \gamma(\beta')|$.
3. $\pi$ — наименьшее положительное число, для которого $\gamma(\pi)$ диаметрально противоположно $\gamma(0)$, то есть $\gamma(\pi) = -\gamma(0) = (-1, 0)$.
4. Параметризация ориентирована против часовой стрелки: для $0 < \theta < \pi/2$ точка $\gamma(\theta)$ находится в верхней полуплоскости ($y > 0$).

## Замечания

- Число $\pi$ вводится этой аксиомой как символ — наименьший положительный период параметризации, при котором достигается диаметральная противоположность. Численное значение $\pi$ не определяется в A6 и будет установлено в разделе интегрального исчисления через длину окружности.
- Свойство 2 (равным дугам — равные хорды) является ключом к выводу всех тригонометрических тождеств без обращения к геометрии треугольников.
- Функция $\gamma$ задаёт равномерное движение по окружности, где параметр $\theta$ играет роль длины дуги от начальной точки.
