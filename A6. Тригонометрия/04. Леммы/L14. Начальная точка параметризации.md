## Формулировка

Начальная точка параметризации $\gamma$ имеет координаты $(1, 0)$:

$$\gamma(0) = (1, 0)$$

Следовательно:

$$\cos 0 = 1, \qquad \sin 0 = 0$$

---

## Основано на

- [[A14. Равномерная параметризация окружности]]
- [[D59. Синус]]
- [[D60. Косинус]]

---

## Доказательство

По аксиоме A14, свойство 1: $\gamma(0) = (1, 0)$.

По определению D60, $\cos 0$ — абсцисса точки $\gamma(0)$, то есть $1$.

По определению D59, $\sin 0$ — ордината точки $\gamma(0)$, то есть $0$.

Лемма доказана.
