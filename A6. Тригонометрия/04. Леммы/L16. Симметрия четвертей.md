## Формулировка

Параметризация $\gamma$ обладает симметрией четвертей:

1. $\gamma(\pi/2) = (0, 1)$ — четверть оборота.
2. $\gamma(\pi) = (-1, 0)$ — половина оборота.
3. $\gamma(3\pi/2) = (0, -1)$ — три четверти оборота.

Следовательно:

$$\cos\frac{\pi}{2} = 0, \quad \sin\frac{\pi}{2} = 1, \quad \cos\pi = -1, \quad \sin\pi = 0, \quad \cos\frac{3\pi}{2} = 0, \quad \sin\frac{3\pi}{2} = -1$$

## Доказательство

**$\gamma(\pi) = (-1, 0)$.** По A14, свойство 3: $\gamma(\pi)$ диаметрально противоположно $\gamma(0) = (1, 0)$, то есть $\gamma(\pi) = (-1, 0)$. Следовательно, $\cos\pi = -1$, $\sin\pi = 0$.

**$\gamma(\pi/2) = (0, 1)$.** Угол $\pi/2$ — половина от $\pi$, то есть середина дуги между $\gamma(0) = (1, 0)$ и $\gamma(\pi) = (-1, 0)$. По симметрии окружности (A14, свойство 2 — равным дугам соответствуют равные хорды), точка $\gamma(\pi/2)$ равноудалена от $\gamma(0)$ и $\gamma(\pi)$.

Пусть $\gamma(\pi/2) = (x, y)$. Тогда:

- $x^2 + y^2 = 1$ (точка на единичной окружности).
- $|\gamma(\pi/2) - \gamma(0)|^2 = |\gamma(\pi/2) - \gamma(\pi)|^2$ (равноудалённость).

Вычисляем: $(x-1)^2 + y^2 = (x+1)^2 + y^2$, откуда $x^2 - 2x + 1 = x^2 + 2x + 1$, то есть $-4x = 0$, $x = 0$. Тогда $y^2 = 1$, и по A14, свойство 4 (ориентация против часовой стрелки), $y > 0$, значит $y = 1$.

**$\gamma(3\pi/2) = (0, -1)$.** Угол $3\pi/2$ — середина дуги между $\gamma(\pi) = (-1, 0)$ и $\gamma(2\pi) = \gamma(0) = (1, 0)$. Аналогично, $x = 0$, $y^2 = 1$, и $y < 0$ (нижняя полуплоскость), значит $y = -1$.

Лемма доказана.
