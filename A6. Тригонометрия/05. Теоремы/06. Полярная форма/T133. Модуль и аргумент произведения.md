## Формулировка

Для любых двух ненулевых комплексных чисел $z_1, z_2$ в полярной форме $z_k = r_k\exp(i\theta_k)$:

$$|z_1 z_2| = |z_1| \cdot |z_2|$$

$$\arg(z_1 z_2) = \arg z_1 + \arg z_2 \pmod{2\pi}$$

## Доказательство

Пусть $z_1 = r_1\exp(i\theta_1)$, $z_2 = r_2\exp(i\theta_2)$.

По T124:

$$z_1 z_2 = r_1 r_2 \exp(i\theta_1)\exp(i\theta_2) = r_1 r_2 \exp(i(\theta_1 + \theta_2))$$

Следовательно:

- Модуль: $|z_1 z_2| = r_1 r_2 = |z_1| \cdot |z_2|$.
- Аргумент: $\arg(z_1 z_2) = \theta_1 + \theta_2 = \arg z_1 + \arg z_2$ (с точностью до $2\pi$ по T118).

Теорема доказана.
