## Формулировка

Для любого ненулевого $z \in \mathbb{C}$ в полярной форме $z = r\exp(i\theta)$ и любого $n \in \mathbb{N}$, $n \ge 1$, существует ровно $n$ различных корней $n$-й степени из $z$, задаваемых формулой:

$$w_k = r^{1/n}\exp\left(i\frac{\theta + 2\pi k}{n}\right), \quad k = 0, 1, \dots, n-1$$

## Доказательство

Пусть $w = \rho\exp(i\phi)$ — корень $n$-й степени из $z = r\exp(i\theta)$. Тогда $w^n = z$.

По T125: $w^n = \rho^n\exp(in\phi)$. По T133: $|w^n| = \rho^n = r$ и $\arg(w^n) = n\phi = \theta + 2\pi k$ для некоторого $k \in \mathbb{Z}$.

Откуда:

$$\rho = r^{1/n}, \qquad \phi = \frac{\theta + 2\pi k}{n}$$

**Различность.** Для $k = 0, 1, \dots, n-1$ получаем $n$ различных углов $\phi_k$ в промежутке $[0, 2\pi)$, так как разность между соседними:

$$\phi_{k+1} - \phi_k = \frac{2\pi}{n} < 2\pi$$

**Полнота.** Для $k = n$ получаем $\phi_n = \frac{\theta + 2\pi n}{n} = \frac{\theta}{n} + 2\pi = \phi_0 + 2\pi$, что по T118 даёт ту же точку. Значит, корней ровно $n$.

Теорема доказана.
