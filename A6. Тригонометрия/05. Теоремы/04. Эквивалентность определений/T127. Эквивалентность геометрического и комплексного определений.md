## Формулировка

Определения D59/D60 (синус и косинус как координаты точки на окружности) и D65 (синус и косинус через комплексную экспоненту) согласованы:

$$\frac{\exp(i\theta) - \exp(-i\theta)}{2i} = \sin\theta, \qquad \frac{\exp(i\theta) + \exp(-i\theta)}{2} = \cos\theta$$

## Доказательство

По D64:

$$\exp(i\theta) = \cos\theta + i\sin\theta$$

По T117: $\cos(-\theta) = \cos\theta$, $\sin(-\theta) = -\sin\theta$. Следовательно:

$$\exp(-i\theta) = \cos(-\theta) + i\sin(-\theta) = \cos\theta - i\sin\theta$$

Вычисляем:

$$\exp(i\theta) + \exp(-i\theta) = (\cos\theta + i\sin\theta) + (\cos\theta - i\sin\theta) = 2\cos\theta$$

$$\exp(i\theta) - \exp(-i\theta) = (\cos\theta + i\sin\theta) - (\cos\theta - i\sin\theta) = 2i\sin\theta$$

Откуда:

$$\cos\theta = \frac{\exp(i\theta) + \exp(-i\theta)}{2}, \qquad \sin\theta = \frac{\exp(i\theta) - \exp(-i\theta)}{2i}$$

Это совпадает с D65. Теорема доказана.
