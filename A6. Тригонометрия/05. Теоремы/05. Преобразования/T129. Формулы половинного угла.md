## Формулировка

Для любого $\theta \in \mathbb{R}$:

$$\cos\frac{\theta}{2} = \pm\sqrt{\frac{1 + \cos\theta}{2}}, \qquad \sin\frac{\theta}{2} = \pm\sqrt{\frac{1 - \cos\theta}{2}}$$

$$\tan\frac{\theta}{2} = \frac{1 - \cos\theta}{\sin\theta} = \frac{\sin\theta}{1 + \cos\theta}$$

Знак определяется четвертью, в которой находится $\theta/2$.

## Доказательство

Из T128: $\cos 2\phi = 2\cos^2\phi - 1$. Положим $\phi = \theta/2$:

$$\cos\theta = 2\cos^2\frac{\theta}{2} - 1$$

Откуда:

$$\cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}, \qquad \cos\frac{\theta}{2} = \pm\sqrt{\frac{1 + \cos\theta}{2}}$$

Аналогично, из $\cos 2\phi = 1 - 2\sin^2\phi$:

$$\sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2}, \qquad \sin\frac{\theta}{2} = \pm\sqrt{\frac{1 - \cos\theta}{2}}$$

Для тангенса:

$$\tan\frac{\theta}{2} = \frac{\sin\frac{\theta}{2}}{\cos\frac{\theta}{2}} = \frac{2\sin\frac{\theta}{2}\cos\frac{\theta}{2}}{2\cos^2\frac{\theta}{2}} = \frac{\sin\theta}{1 + \cos\theta}$$

(использовано T128: $2\sin\frac{\theta}{2}\cos\frac{\theta}{2} = \sin\theta$).

Аналогично:

$$\tan\frac{\theta}{2} = \frac{2\sin^2\frac{\theta}{2}}{2\sin\frac{\theta}{2}\cos\frac{\theta}{2}} = \frac{1 - \cos\theta}{\sin\theta}$$

Теорема доказана.
