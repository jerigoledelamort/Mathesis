## Формулировка

Для любого $\theta \in \mathbb{R}$ и $k \in \mathbb{Z}$:

| Угол | $\sin$ | $\cos$ | $\tan$ |
|------|--------|--------|--------|
| $\theta + \pi$ | $-\sin\theta$ | $-\cos\theta$ | $\tan\theta$ |
| $\theta + \frac{\pi}{2}$ | $\cos\theta$ | $-\sin\theta$ | $-\cot\theta$ |
| $\frac{\pi}{2} - \theta$ | $\cos\theta$ | $\sin\theta$ | $\cot\theta$ |
| $\pi - \theta$ | $\sin\theta$ | $-\cos\theta$ | $-\tan\theta$ |

## Доказательство

**$\theta + \pi$:** По T121 и T120 с $\beta = \pi$, используя L16 ($\sin\pi = 0$, $\cos\pi = -1$):

$$\sin(\theta + \pi) = \sin\theta\cos\pi + \cos\theta\sin\pi = -\sin\theta$$

$$\cos(\theta + \pi) = \cos\theta\cos\pi - \sin\theta\sin\pi = -\cos\theta$$

**$\theta + \frac{\pi}{2}$:** По T121 и T120 с $\beta = \pi/2$, используя L16 ($\sin\frac{\pi}{2} = 1$, $\cos\frac{\pi}{2} = 0$):

$$\sin\left(\theta + \frac{\pi}{2}\right) = \sin\theta \cdot 0 + \cos\theta \cdot 1 = \cos\theta$$

$$\cos\left(\theta + \frac{\pi}{2}\right) = \cos\theta \cdot 0 - \sin\theta \cdot 1 = -\sin\theta$$

**$\frac{\pi}{2} - \theta$:** По T119 с $\alpha = \pi/2$, $\beta = \theta$:

$$\cos\left(\frac{\pi}{2} - \theta\right) = \cos\frac{\pi}{2}\cos\theta + \sin\frac{\pi}{2}\sin\theta = \sin\theta$$

$$\sin\left(\frac{\pi}{2} - \theta\right) = \cos\theta$$

(последнее — из T121 или из $\sin(\frac{\pi}{2} - \theta) = \cos(\frac{\pi}{2} - (\frac{\pi}{2} - \theta)) = \cos\theta$).

**$\pi - \theta$:** По T119 с $\alpha = \pi$, $\beta = \theta$:

$$\cos(\pi - \theta) = \cos\pi\cos\theta + \sin\pi\sin\theta = -\cos\theta$$

$$\sin(\pi - \theta) = \sin\pi\cos\theta - \cos\pi\sin\theta = \sin\theta$$

Теорема доказана.
