## Формулировка

Для любых $\alpha, \beta \in \mathbb{R}$:

$$\exp(i(\alpha + \beta)) = \exp(i\alpha) \cdot \exp(i\beta)$$

---

## Основано на

- [[D64. Комплексная экспонента на мнимой оси]]
- [[D29. Сложение комплексных чисел]]
- [[D30. Умножение комплексных чисел]]
- [[T120. Косинус суммы]]
- [[T121. Синус суммы и разности]]

---

## Доказательство

По D64:

$$\exp(i(\alpha + \beta)) = \cos(\alpha + \beta) + i\sin(\alpha + \beta)$$

С другой стороны:

$$\exp(i\alpha) \cdot \exp(i\beta) = (\cos\alpha + i\sin\alpha)(\cos\beta + i\sin\beta)$$

Раскрываем произведение по правилам умножения комплексных чисел (D30), используя $i^2 = -1$ (T91):

$$= \cos\alpha\cos\beta + i\cos\alpha\sin\beta + i\sin\alpha\cos\beta + i^2\sin\alpha\sin\beta$$

$$= (\cos\alpha\cos\beta - \sin\alpha\sin\beta) + i(\sin\alpha\cos\beta + \cos\alpha\sin\beta)$$

По T120: $\cos\alpha\cos\beta - \sin\alpha\sin\beta = \cos(\alpha + \beta)$.

По T121: $\sin\alpha\cos\beta + \cos\alpha\sin\beta = \sin(\alpha + \beta)$.

Следовательно:

$$\exp(i\alpha) \cdot \exp(i\beta) = \cos(\alpha + \beta) + i\sin(\alpha + \beta) = \exp(i(\alpha + \beta))$$

Теорема доказана.
