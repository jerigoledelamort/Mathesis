## Формулировка

$$\sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}, \quad \cos\frac{\pi}{3} = \frac{1}{2}$$

$$\tan\frac{\pi}{3} = \sqrt{3}$$

## Доказательство

Угол $\pi/3$ — одна шестая полного оборота ($6 \cdot \frac{\pi}{3} = 2\pi$). По T125:

$$\left(\exp\left(i\frac{\pi}{3}\right)\right)^6 = \exp(i \cdot 2\pi) = \cos 2\pi + i\sin 2\pi = 1$$

(по T137 и T118: $\cos 2\pi = \cos 0 = 1$, $\sin 2\pi = \sin 0 = 0$).

Пусть $c = \cos\frac{\pi}{3}$, $s = \sin\frac{\pi}{3}$. Тогда $(c + is)^6 = 1$.

Вычислим $(c + is)^6$ через последовательное возведение в квадрат и куб:

$$(c + is)^2 = c^2 - s^2 + 2ics$$

$$(c + is)^3 = (c + is)(c^2 - s^2 + 2ics) = c^3 - 3cs^2 + i(3c^2 s - s^3)$$

$$(c + is)^6 = \left[(c + is)^3\right]^2 = (c^3 - 3cs^2)^2 - (3c^2 s - s^3)^2 + 2i(c^3 - 3cs^2)(3c^2 s - s^3)$$

Условие $(c+is)^6 = 1$ даёт: мнимая часть равна 0, вещественная равна 1.

**Мнимая часть:** $(c^3 - 3cs^2)(3c^2 s - s^3) = 0$.

Используя $s^2 = 1 - c^2$ (T116):

- $c^3 - 3cs^2 = c^3 - 3c(1 - c^2) = 4c^3 - 3c$
- $3c^2 s - s^3 = s(3c^2 - s^2) = s(3c^2 - 1 + c^2) = s(4c^2 - 1)$

Произведение: $cs(4c^2 - 1)(4c^2 - 3) = 0$.

Так как $\pi/3$ — в первой четверти, $c \neq 0$ и $s \neq 0$. Значит:

$$4c^2 - 1 = 0 \quad \text{или} \quad 4c^2 - 3 = 0$$

**Вещественная часть:** $(4c^3 - 3c)^2 - s^2(4c^2 - 1)^2 = 1$.

Проверим $c = \frac{1}{2}$ (из $4c^2 - 1 = 0$, положительный корень):

$$c = \frac{1}{2}, \quad s = \sqrt{1 - \frac{1}{4}} = \frac{\sqrt{3}}{2}$$

Проверим $c = \frac{\sqrt{3}}{2}$ (из $4c^2 - 3 = 0$):

$$c = \frac{\sqrt{3}}{2}, \quad s = \frac{1}{2}$$

Это соответствует углу $\pi/6$, а не $\pi/3$ (так как при $\pi/3$ косинус должен быть меньше синуса — точка ближе к $(0,1)$, чем к $(1,0)$, поскольку $\pi/3 > \pi/4$). Значит, правильный ответ для $\pi/3$:

$$\cos\frac{\pi}{3} = \frac{1}{2}, \quad \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$$

$$\tan\frac{\pi}{3} = \frac{\sqrt{3}/2}{1/2} = \sqrt{3}$$

Теорема доказана.
