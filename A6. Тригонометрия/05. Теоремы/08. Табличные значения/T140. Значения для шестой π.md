## Формулировка

$$\sin\frac{\pi}{6} = \frac{1}{2}, \quad \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$$

$$\tan\frac{\pi}{6} = \frac{\sqrt{3}}{3} = \frac{1}{\sqrt{3}}$$

## Доказательство

Угол $\pi/6$ — половина угла $\pi/3$. Применим T129 (формула половинного угла) с $\theta = \pi/3$:

$$\cos\frac{\pi}{6} = \cos\frac{\pi/3}{2} = \sqrt{\frac{1 + \cos(\pi/3)}{2}}$$

По T139: $\cos\frac{\pi}{3} = \frac{1}{2}$. Подставляем:

$$\cos\frac{\pi}{6} = \sqrt{\frac{1 + 1/2}{2}} = \sqrt{\frac{3/2}{2}} = \sqrt{\frac{3}{4}} = \frac{\sqrt{3}}{2}$$

(положительный корень, так как $\pi/6$ в первой четверти).

По T116:

$$\sin\frac{\pi}{6} = \sqrt{1 - \cos^2\frac{\pi}{6}} = \sqrt{1 - \frac{3}{4}} = \sqrt{\frac{1}{4}} = \frac{1}{2}$$

(положительный корень, первая четверть).

$$\tan\frac{\pi}{6} = \frac{\sin(\pi/6)}{\cos(\pi/6)} = \frac{1/2}{\sqrt{3}/2} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

Теорема доказана.
