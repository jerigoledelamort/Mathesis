## Формулировка

$$\sin 0 = 0, \quad \cos 0 = 1$$

$$\sin\frac{\pi}{2} = 1, \quad \cos\frac{\pi}{2} = 0$$

$$\sin\pi = 0, \quad \cos\pi = -1$$

$$\sin\frac{3\pi}{2} = -1, \quad \cos\frac{3\pi}{2} = 0$$

---

## Основано на

- [[L14. Начальная точка параметризации]]
- [[L16. Симметрия четвертей]]

---

## Доказательство

Все значения непосредственно следуют из L14 и L16:

- L14: $\gamma(0) = (1, 0)$ → $\cos 0 = 1$, $\sin 0 = 0$.
- L16: $\gamma(\pi/2) = (0, 1)$ → $\cos\frac{\pi}{2} = 0$, $\sin\frac{\pi}{2} = 1$.
- L16: $\gamma(\pi) = (-1, 0)$ → $\cos\pi = -1$, $\sin\pi = 0$.
- L16: $\gamma(3\pi/2) = (0, -1)$ → $\cos\frac{3\pi}{2} = 0$, $\sin\frac{3\pi}{2} = -1$.

Теорема доказана.
