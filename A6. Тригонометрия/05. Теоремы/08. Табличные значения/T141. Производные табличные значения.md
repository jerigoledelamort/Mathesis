## Формулировка

Все значения тригонометрических функций во всех четвертях получаются из значений первой четверти (T137–T140) через симметрии:

- T117 (чётность/нечётность) — для отрицательных углов.
- T118 (периодичность) — для сдвигов на $2\pi k$.
- T130 (формулы приведения) — для отражений между четвертями.

## Доказательство

Значения в первой четверти ($0 \le \theta \le \pi/2$) установлены в T137–T140:

| $\theta$ | $\sin\theta$ | $\cos\theta$ |
|-----------|-------------|-------------|
| $0$ | $0$ | $1$ |
| $\pi/6$ | $1/2$ | $\sqrt{3}/2$ |
| $\pi/4$ | $\sqrt{2}/2$ | $\sqrt{2}/2$ |
| $\pi/3$ | $\sqrt{3}/2$ | $1/2$ |
| $\pi/2$ | $1$ | $0$ |

**Вторая четверть** ($\pi/2 < \theta < \pi$): по T130, $\sin(\pi - \alpha) = \sin\alpha$, $\cos(\pi - \alpha) = -\cos\alpha$.

**Третья четверть** ($\pi < \theta < 3\pi/2$): по T130, $\sin(\pi + \alpha) = -\sin\alpha$, $\cos(\pi + \alpha) = -\cos\alpha$.

**Четвёртая четверть** ($3\pi/2 < \theta < 2\pi$): по T117 и T130, $\sin(2\pi - \alpha) = -\sin\alpha$, $\cos(2\pi - \alpha) = \cos\alpha$.

Таким образом, из пяти значений первой четверти получаются все значения во всех четвертях. Теорема доказана.
