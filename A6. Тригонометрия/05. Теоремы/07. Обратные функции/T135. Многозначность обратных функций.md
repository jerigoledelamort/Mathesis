## Формулировка

Обратные тригонометрические функции многозначны: для каждого значения $x$ в области определения существует бесконечно много углов $\theta$, удовлетворяющих соответствующему уравнению.

## Доказательство

По T118, $\sin(\theta + 2\pi k) = \sin\theta$ для любого $k \in \mathbb{Z}$. Поэтому если $\sin\theta = x$, то и $\sin(\theta + 2\pi k) = x$ для всех $k$. Решение не единственно.

Дополнительно, по T130: $\sin(\pi - \theta) = \sin\theta$, поэтому решения симметричны относительно $\pi/2$.

Аналогично для косинуса: $\cos(\theta + 2\pi k) = \cos\theta$ и $\cos(-\theta) = \cos\theta$ (T117).

Для тангенса: $\tan(\theta + \pi k) = \tan\theta$ (следствие T130: $\tan(\theta + \pi) = \tan\theta$).

Теорема доказана.
