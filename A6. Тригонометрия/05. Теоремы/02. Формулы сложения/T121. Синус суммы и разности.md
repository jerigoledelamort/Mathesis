## Формулировка

Для любых $\alpha, \beta \in \mathbb{R}$:

$$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$$

$$\sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta$$

## Доказательство

Используем T119 с заменой $\alpha \to \frac{\pi}{2} - \beta$ и $\beta \to \alpha$:

$$\cos\left(\frac{\pi}{2} - \beta - \alpha\right) = \cos\left(\frac{\pi}{2} - \beta\right)\cos\alpha + \sin\left(\frac{\pi}{2} - \beta\right)\sin\alpha$$

По L16, $\cos(\pi/2) = 0$, $\sin(\pi/2) = 1$. Установим вспомогательные тождества.

**$\cos(\frac{\pi}{2} - \beta) = \sin\beta$.** По T119:

$$\cos\left(\frac{\pi}{2} - \beta\right) = \cos\frac{\pi}{2}\cos\beta + \sin\frac{\pi}{2}\sin\beta = 0 \cdot \cos\beta + 1 \cdot \sin\beta = \sin\beta$$

**$\sin(\frac{\pi}{2} - \beta) = \cos\beta$.** Поскольку $\sin(\frac{\pi}{2} - \beta) = \cos(\beta - \frac{\pi}{2} + \frac{\pi}{2})$. Сначала заметим, что $\sin\theta = \cos(\frac{\pi}{2} - \theta)$ (доказано выше). Тогда:

$$\sin\left(\frac{\pi}{2} - \beta\right) = \cos\left(\frac{\pi}{2} - \left(\frac{\pi}{2} - \beta\right)\right) = \cos\beta$$

Теперь подставляем:

$$\cos\left(\frac{\pi}{2} - (\alpha + \beta)\right) = \sin\beta\cos\alpha + \cos\beta\sin\alpha$$

Левая часть равна $\sin(\alpha + \beta)$ (по тождеству $\sin\theta = \cos(\frac{\pi}{2} - \theta)$). Следовательно:

$$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$$

Формула для $\sin(\alpha - \beta)$ получается заменой $\beta \to -\beta$ и применением T117:

$$\sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta$$

Теорема доказана.
