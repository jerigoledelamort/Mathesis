## Формулировка

Для любых $\alpha, \beta \in \mathbb{R}$, где определены тангенсы:

$$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$

$$\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$$

## Доказательство

По определению D61:

$$\tan(\alpha + \beta) = \frac{\sin(\alpha + \beta)}{\cos(\alpha + \beta)}$$

Подставляем T121 и T120:

$$= \frac{\sin\alpha\cos\beta + \cos\alpha\sin\beta}{\cos\alpha\cos\beta - \sin\alpha\sin\beta}$$

Делим числитель и знаменатель на $\cos\alpha\cos\beta$ (предполагая $\cos\alpha \neq 0$ и $\cos\beta \neq 0$):

$$= \frac{\frac{\sin\alpha}{\cos\alpha} + \frac{\sin\beta}{\cos\beta}}{1 - \frac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta}} = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$

Формула для $\tan(\alpha - \beta)$ получается заменой $\beta \to -\beta$ и использованием $\tan(-\beta) = -\tan\beta$ (следствие T117):

$$\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$$

Теорема доказана.
