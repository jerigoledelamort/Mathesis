## Определение

Операция вычисления расстояния по двум точкам $A$ и $B$ возвращает неотрицательное вещественное число $d$, удовлетворяющее аксиомам метрики (A9).

$$d = \text{dist}(A, B)$$

Для выбранной L₂-метрики:

$$d(A, B) = \sqrt{\sum_{i=1}^n (a_i - b_i)^2}$$

## Алгоритм

1. Вход: точки $A = (a_1, \dots, a_n)$, $B = (b_1, \dots, b_n)$.
2. Вычислить разности $(a_i - b_i)$ для каждой координаты.
3. Возвести каждую разность в квадрат.
4. Суммировать все квадраты.
5. Извлечь квадратный корень (операция определена в A2).
6. Выдать результат.
