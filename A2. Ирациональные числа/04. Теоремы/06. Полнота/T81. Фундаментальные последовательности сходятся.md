## Доказательство

Пусть $(x_n)_{n=1}^{\infty}$ — фундаментальная последовательность вещественных чисел.

Каждое $x_n$ представляется некоторой фундаментальной последовательностью рациональных чисел. Зафиксируем для каждого $n$ представителя $(\alpha_{n,k})_{k=1}^{\infty}$ числа $x_n$.

Поскольку $x_n$ само по себе является вещественным числом, для каждого $n$ существует такой индекс $k_n$, что для всех $k\ge k_n$ выполняется

$$|\alpha_{n,k} - x_n| < \frac{1}{n}.$$

Теперь определим последовательность рациональных чисел

$$\beta_n := \alpha_{n,k_n}.$$

Докажем, что $(\beta_n)$ фундаментальна. Возьмём произвольное $\varepsilon>0$. Так как $(x_n)$ фундаментальна, существует $N_1$ такое, что для всех $n,m\ge N_1$ выполняется

$$|x_n-x_m| < \frac{\varepsilon}{3}.$$

Выберем $N_2$ так, чтобы для всех $n\ge N_2$ выполнялось $\frac{2}{n}<\frac{\varepsilon}{3}$. Пусть $N=\max(N_1,N_2)$.

Тогда для всех $n,m\ge N$:

$$|\beta_n-\beta_m| \le |\beta_n-x_n| + |x_n-x_m| + |x_m-\beta_m| < \frac{1}{n}+\frac{\varepsilon}{3}+\frac{1}{m} < \varepsilon.$$

Следовательно, $(\beta_n)$ — фундаментальная последовательность рациональных чисел. По определению [[D22. Вещественное число]] она задаёт некоторое вещественное число

$$x=[(\beta_n)].$$

Остаётся показать, что $x_n\to x$. Для любого $\varepsilon>0$ выберем $N$ настолько большим, чтобы $\frac{1}{N}<\frac{\varepsilon}{2}$. Тогда для всех $n\ge N$:

$$|x_n-x| \le |x_n-\beta_n| + |\beta_n-x| < \frac{1}{n}+\frac{\varepsilon}{2} < \varepsilon.$$

Значит, последовательность $(x_n)$ сходится к $x$. Теорема доказана.
