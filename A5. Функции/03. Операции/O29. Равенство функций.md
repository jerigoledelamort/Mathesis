## Определение

Две функции $f$ и $g$ считаются равными, если их области определения совпадают и для каждого аргумента $x$ из этой области выполняется $f(x) = g(x)$.

## Алгоритм

1. Вход: две функции $f$, $g$.
2. Проверить, совпадают ли их области определения.
3. Если нет — функции не равны.
4. Для каждого $x$ из области определения проверить, выполняется ли $f(x) = g(x)$.
5. Если для всех $x$ равенство выполняется — функции равны. Иначе — не равны.
