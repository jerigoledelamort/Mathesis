## Определение

Для двух скалярных функций $f$ и $g$ с областями определения $D_f$ и $D_g$ их сумма $f + g$ определяется поточечно:

$$(f + g)(x) = f(x) + g(x)$$

Область определения суммы: $D_{f+g} = D_f \cap D_g$.

## Алгоритм

1. Вход: две скалярные функции $f$, $g$.
2. Найти пересечение их областей определения: $D = D_f \cap D_g$.
3. Для каждого $x \in D$ вычислить $f(x) + g(x)$.
4. Результат — функция с областью определения $D$.
