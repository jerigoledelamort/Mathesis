## Определение

Для двух функций $f: X \to Y$ и $g: Y \to Z$, где область значений $f$ содержится в области определения $g$, композиция $g \circ f$ определяется поточечно:

$$(g \circ f)(x) = g(f(x))$$

Область определения композиции:

$$D_{g \circ f} = \{ x \in D_f \mid f(x) \in D_g \}$$

## Алгоритм

1. Вход: две функции $f$, $g$.
2. Проверить, что область значений $f$ содержится в области определения $g$.
3. Найти множество $D = \{ x \in D_f \mid f(x) \in D_g \}$.
4. Для каждого $x \in D$ вычислить $g(f(x))$.
5. Результат — функция с областью определения $D$.
